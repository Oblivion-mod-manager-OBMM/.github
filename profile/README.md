# Oblivion Mod Manager: Plugin Control, OMOD Packaging, and Utility Tools for The Elder Scrolls IV: Oblivion

Oblivion Mod Manager (OBMM) brings plugin selection and mod installation into one interface for The Elder Scrolls IV: Oblivion, while also allowing mods to be packaged as reusable OMOD archives. It can serve as an expanded alternative to the game's Data Files selector or manage mods distributed in OMOD format, with additional utilities for archives, plugin conflicts, and save-specific plugin lists.

## Plugin Selection and Load Order

OBMM provides a central view of the Oblivion plugins available to the game. Rather than relying only on the launcher's basic Data Files selector, players can use the manager to review the plugin list, enable or disable entries, and change their order with the available move controls.

This makes the active plugin setup visible in one place. When working with a collection of installed mods, the list helps distinguish the plugins currently selected for the game from packages stored in the manager. OBMM can therefore be used for straightforward plugin selection as well as more involved mod setups that require managing several installed additions.

The interface also includes controls for launching Oblivion and accessing the manager's other tools, keeping common plugin and mod-management actions together.

## OMOD Packages and Mod Installation

A central OBMM feature is its support for OMOD files, the package format used by the manager to distribute and install Oblivion mods. Mods specially packed as OMOD archives can be added to the manager and handled as individual entries instead of being treated only as loose files copied into the game directory.

OBMM also includes an OMOD creation workflow. A package can be assembled from a mod's files and supplied with identifying information such as its name, version, author, and description. The package can then be kept in the OMOD list for activation or deactivation through the manager.

For players who install and remove mods regularly, this separates the installed package collection from the plugin selection used for a game session. It also gives mod creators a way to prepare their files in a format that OBMM users can install through the same interface.

## Built-In Modding Utilities

OBMM includes several supporting tools beyond plugin selection and OMOD handling:

- **BSA unpacker:** extracts files from Oblivion BSA archives.
- **Conflict detector:** helps identify conflicts between mod files.
- **Archive invalidation generator:** creates an `archiveinvalidation.txt` file used by Oblivion mod setups.
- **Batch actions:** an additional set of operations available from the main interface.
- **Import and export:** controls for importing and exporting manager data.

These utilities cover common tasks that arise when working with game archives and multiple mods. Instead of limiting OBMM to a plugin checklist, they make it a broader management utility for an installed Oblivion mod collection.

## Save-Specific Plugin Lists

The save file manager can synchronize the active plugin list with an individual save game. This is useful when different characters or playthroughs use different combinations of mods: the plugin configuration associated with a save can be kept aligned with the setup that was active for it.

The feature addresses a different part of mod management from package installation. OMOD entries represent available mod packages, the main plugin list represents the current game setup, and save synchronization links that setup to a particular save.

## Two Ways to Manage an Oblivion Setup

OBMM can be used at different levels depending on how a player organizes mods. For a simple setup, it works as an enhanced Data Files selector for choosing and ordering plugins. For a larger collection, OMOD support adds package creation and management, while the included utilities handle related archive and file-management tasks.

This combination makes Oblivion Mod Manager relevant both to players maintaining an existing plugin list and to users who distribute or install mods as OMOD packages. Its role is specific to managing Oblivion's plugins, mod packages, archives, and save-linked plugin configurations.
